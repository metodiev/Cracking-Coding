# Implementing a Suffix Array (Doubling Algorithm)

##  Problem Statement

Given a string `s` of length `N`, build its **Suffix Array** — an array of integers representing the starting indices of all suffixes of `s`, sorted in lexicographical order.

Suffix arrays are a core data structure in:

* Full‑text search
* Pattern matching
* Data compression (e.g. Burrows–Wheeler Transform)
* Bioinformatics (DNA sequence analysis)


##  What is a Suffix Array?

For a string:

```
s = "banana"
```

All suffixes:

```
0 → banana
1 → anana
2 → nana
3 → ana
4 → na
5 → a
```

Sorted suffixes:

```
5 → a
3 → ana
1 → anana
0 → banana
4 → na
2 → nana
```

###  Suffix Array

```
[5, 3, 1, 0, 4, 2]
```


##  Algorithm Choice

There are two common approaches:

| Algorithm    | Time           | Complexity | Notes                 |
| ------------ | -------------- | ---------- | --------------------- |
| SA‑IS        | O(n)           | Complex    | Used in libraries     |
| **Doubling** | **O(n log n)** | Simple     | Interview & practical |

For **medium N**, the **Doubling Algorithm** is the best balance between clarity and performance.


## Doubling Algorithm – Core Idea

1. Start by ranking suffixes based on **first character**
2. Iteratively double the comparison length:

   * 1 char → 2 chars → 4 chars → 8 chars …
3. At each step:

   * Sort suffixes by `(rank[i], rank[i + k])`
   * Re‑assign ranks
4. Stop when `k ≥ N`


## Why it Works

At step `k`, suffixes are correctly sorted by their **first `2k` characters**.

By doubling each iteration, we converge in **log₂(N)** steps.



## Python Implementation (Doubling)

```python
def build_suffix_array(s):
    n = len(s)
    sa = list(range(n))              # suffix indices
    rank = [ord(c) for c in s]       # initial ranks
    tmp = [0] * n

    k = 1
    while k < n:
        sa.sort(key=lambda i: (rank[i], rank[i + k] if i + k < n else -1))

        tmp[sa[0]] = 0
        for i in range(1, n):
            prev, curr = sa[i - 1], sa[i]
            tmp[curr] = tmp[prev] + (
                (rank[prev], rank[prev + k] if prev + k < n else -1) <
                (rank[curr], rank[curr + k] if curr + k < n else -1)
            )

        rank, tmp = tmp, rank
        k <<= 1

    return sa
```


##  Example

```python
s = "banana"
print(build_suffix_array(s))
```

### Output

```
[5, 3, 1, 0, 4, 2]
```


##  Complexity Analysis

| Metric | Value          |
| ------ | -------------- |
| Time   | **O(n log n)** |
| Space  | **O(n)**       |

Efficient enough for **hundreds of thousands of characters** in Python.


##  Key Implementation Details

* `rank[i]` → current rank of suffix at index `i`
* `rank[i + k]` → rank of the second half
* `-1` → ensures shorter suffixes sort first
* Bit‑shift (`k <<= 1`) → doubling step


##  Common Pitfalls

* Forgetting bounds check for `i + k`
* Using string slices (slow)
* Not updating ranks correctly
* Expecting Python to handle very large N (use C++ for that)


##  Extensions

* Build **LCP array (Kasai algorithm)**
* Pattern matching with binary search
* Convert to **Java** or **C++**
* Implement **SA‑IS** for linear time


##  Summary

> The doubling algorithm is the **best practical suffix array implementation** for medium‑sized inputs.

* Clean
* Deterministic
* Interview‑ready
* Production‑usable
