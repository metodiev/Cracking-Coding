# Reverse a String in Java

There are at least 6 common ways to reverse a string in Java:
1. Using StringBuilder or StringBuffer
2.  Using a for loop (iterating backwards)
3. Using recursion
4. Using character array
5. Using Java 8 Streams
6. Using Collections.reverse()

## 1. Using StringBuilder / StringBuffer
```java
public class ReverseString {
    public static void main(String[] args) {
        String str = "Hello";
        String reversed = new StringBuilder(str).reverse().toString();
        System.out.println(reversed); // Output: olleH
    }
}

```
What it does:

- Creates a StringBuilder object with the original string
- Calls .reverse() which reverses characters in-place
- Converts it back to String

- Time complexity: O(n) → each character is visited once
- Space complexity: O(n) → new string is created

- Pros: Simple, fast, and readable
- Cons: Uses library function (less “manual”)

## 2. Using a for loop (iterating backwards)

```java
public class ReverseString {
    public static void main(String[] args) {
        String str = "Hello";
        String reversed = "";
        for (int i = str.length() - 1; i >= 0; i--) {
            reversed += str.charAt(i);
        }
        System.out.println(reversed); // Output: olleH
    }
}

```
What it does:

 - Starts from the last character of the string
 - Appends each character to a new string

Time complexity: O(n^2) → + operator creates a new string each iteration
Space complexity: O(n) → stores reversed string

## Better alternative: Use StringBuilder inside the loop:

```java
    StringBuilder reversed = new StringBuilder();
    for (int i = str.length() - 1; i >= 0; i--) {
        reversed.append(str.charAt(i));
    }
    System.out.println(reversed.toString());

```

Optimized complexity: O(n) time and space

## 3. Using Recursion


```java
public class ReverseString {
    public static String reverse(String str) {
        if (str.isEmpty()) {
            return str;
        }
        return reverse(str.substring(1)) + str.charAt(0);
    }

    public static void main(String[] args) {
        String str = "Hello";
        System.out.println(reverse(str)); // Output: olleH
    }
}

```

What it does:

- Removes the first character recursively
- Adds it to the reversed substring

Time complexity: O(n^2) → substring creates new strings each call
Space complexity: O(n) → recursion stack depth = string length

Pros: Elegant, functional style
Cons: Stack overflow for very long strings, less efficient

## 4. Using Character Array

```java
public class ReverseString {
    public static void main(String[] args) {
        String str = "Hello";
        char[] chars = str.toCharArray();
        int left = 0, right = chars.length - 1;
        while (left < right) {
            char temp = chars[left];
            chars[left] = chars[right];
            chars[right] = temp;
            left++;
            right--;
        }
        System.out.println(new String(chars)); // Output: olleH
    }
}

```

What it does:

- Converts string to a char array
- Swaps characters from both ends moving to the center

Time complexity: O(n) → each character is visited once
Space complexity: O(n) → char array stores all characters

Pros: Efficient, in-place reversal logic
Cons: Slightly more verbose

## 5. Using Java 8 Streams

```java
import java.util.stream.Collectors;

public class ReverseString {
    public static void main(String[] args) {
        String str = "Hello";
        String reversed = new StringBuilder(
                str.chars()
                   .mapToObj(c -> (char)c)
                   .map(String::valueOf)
                   .collect(Collectors.joining())
        ).reverse().toString();
        System.out.println(reversed); // Output: olleH
    }
}

```

What it does:

- Converts string to stream of characters
- Collects characters into a new string

Reverses using StringBuilder

Time complexity: O(n) → each character is processed once
Space complexity: O(n) → intermediate objects are created

Pros: Functional style, modern Java approach
Cons: Verbose, slower than StringBuilder.reverse()

## 6. Using Collections.reverse()

```java
import java.util.*;

public class ReverseString {
    public static void main(String[] args) {
        String str = "Hello";
        List<Character> chars = new ArrayList<>();
        for (char c : str.toCharArray()) chars.add(c);
        Collections.reverse(chars);
        StringBuilder reversed = new StringBuilder();
        for (char c : chars) reversed.append(c);
        System.out.println(reversed.toString()); // Output: olleH
    }
}

```

What it does:

- Converts string to a List<Character>
- Uses Collections.reverse()
- Converts list back to string

Time complexity: O(n) → iterates characters twice
Space complexity: O(n) → stores list and result string

Pros: Useful for collections, demonstrates Java library
Cons: Verbose for strings

## Summary 

| Method                    | Pros                 | Cons                       |
| ------------------------- | -------------------- | -------------------------- |
| `StringBuilder.reverse()` | Simple, efficient    | Library-based              |
| For loop                  | Educational, manual  | Less efficient with `+`    |
| Recursion                 | Elegant              | Stack risk, less efficient |
| Char array                | Efficient, in-place  | Slightly verbose           |
| Java 8 Streams            | Functional style     | Complex, slower            |
| Collections.reverse()     | Works on collections | Verbose for strings        |
