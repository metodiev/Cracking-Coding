# Tutorials — Cracking the Coding Interview & the 998-Task Roadmap

Welcome to the tutorials section. Every tutorial is a self-contained `.md` file with:

- 📖 **Theory** straight from the *Cracking the Coding Interview (6th Edition)* structure,
- 🧭 **Mermaid diagrams** (flowcharts, sequence diagrams, state machines, class diagrams) — as many as it takes to *see* the algorithm,
- 💻 **Code in four languages** — Java, Python, C# and JavaScript,
- 🔗 **Links to the mapped tasks** in [`tasks/`](../tasks) so you can practice immediately.

> The full mapping of all **998 README tasks** onto the book's chapters lives in
> [**ctci-mapping.md**](ctci-mapping.md) — generated by [`tools/ctci_map.py`](../tools/ctci_map.py).

## Learning path

```mermaid

    C --> D["Ch 5–6<br/>Bits, Math &<br/>Logic"]
    D --> E["Ch 7–8<br/>OOP Design,<br/>Recursion & DP"]
    E --> F["Ch 9–11<br/>System Design,<br/>Sorting, Testing"]

    G --> H["Ch 16–17 & §X<br/>Review problems,<br/>Advanced topics"]

```

## How the pieces fit together

```mermaid
sequenceDiagram
    autonumber
    participant You
    participant Task as Task spec (tasks/…)
    participant Tutorial as Tutorial (tutorials/…)
    participant Solution as Solution (solutions/<lang>/…)
    You->>Task: Read the problem statement
    Task->>Tutorial: Follow the CTCI chapter link
    Tutorial->>You: Learn the pattern (with diagrams + multi-language code)
    You->>Solution: Compare / write your own implementation
    Solution->>You: Run the built-in self-checks
    You->>Task: Mark progress, move to the next tier
```
