# Implementing a Suffix Tree (Ukkonen’s Algorithm)

##  Problem Statement

Implement a **full suffix tree** for a given string using **Ukkonen’s algorithm** and demonstrate that it works efficiently even for **large texts**.

A suffix tree is a powerful data structure that represents **all suffixes of a string** in a compressed trie form.



##  What Is a Suffix Tree?

For a string `s`, a suffix tree contains **all suffixes** of `s` as paths from the root to leaves.

Example for:

```
s = "banana$"
```

Suffixes:

```
banana$
anana$
nana$
ana$
na$
a$
$
```

The suffix tree compresses common prefixes so that:

* Total size is **O(n)**
* All suffixes are represented


##  Suffix Tree vs Suffix Array

| Feature          | Suffix Tree | Suffix Array |
| ---------------- | ----------- | ------------ |
| Build time       | O(n)        | O(n log n)   |
| Space            | High        | Lower        |
| Substring search | O(m)        | O(m log n)   |
| Complexity       | Very high   | Medium       |

Suffix trees are **faster but harder**.


##  Ukkonen’s Algorithm – Why It’s Special

Ukkonen’s algorithm builds the suffix tree:

* **Online** (character by character)
* In **linear time O(n)**
* Without rebuilding from scratch

### Key Ideas

* Implicit suffix tree
* Active point (node, edge, length)
* Suffix links
* Lazy end indices

This is one of the most complex string algorithms in practice.


##  Core Concepts

### Nodes and Edges

* Each edge stores a substring as `(start, end)` indices
* Leaves share a **global end pointer** (dynamic growth)

###  Active Point

Represents where the next extension starts:

```
(active_node, active_edge, active_length)
```

### Suffix Links

* Jump between internal nodes
* Guarantee linear complexity



## Python Implementation (Ukkonen)

This implementation is **educational but complete**. Python is slower than C++, but works for medium‑large inputs.

```python
class End:
    def __init__(self, value):
        self.value = value

class Node:
    def __init__(self):
        self.children = {}
        self.suffix_link = None
        self.start = -1
        self.end = None

class SuffixTree:
    def __init__(self, text):
        self.text = text
        self.root = Node()
        self.root.suffix_link = self.root
        self.active_node = self.root
        self.active_edge = -1
        self.active_length = 0
        self.remaining = 0
        self.leaf_end = End(-1)
        self.build()

    def edge_length(self, node):
        return node.end.value - node.start + 1

    def build(self):
        for i, ch in enumerate(self.text):
            self.leaf_end.value = i
            self.remaining += 1
            last_new_node = None

            while self.remaining > 0:
                if self.active_length == 0:
                    self.active_edge = i

                edge_char = self.text[self.active_edge]

                if edge_char not in self.active_node.children:
                    leaf = Node()
                    leaf.start = i
                    leaf.end = self.leaf_end
                    self.active_node.children[edge_char] = leaf

                    if last_new_node:
                        last_new_node.suffix_link = self.active_node
                        last_new_node = None
                else:
                    next_node = self.active_node.children[edge_char]
                    if self.active_length >= self.edge_length(next_node):
                        self.active_edge += self.edge_length(next_node)
                        self.active_length -= self.edge_length(next_node)
                        self.active_node = next_node
                        continue

                    if self.text[next_node.start + self.active_length] == ch:
                        self.active_length += 1
                        if last_new_node:
                            last_new_node.suffix_link = self.active_node
                        break

                    split = Node()
                    split.start = next_node.start
                    split.end = End(next_node.start + self.active_length - 1)

                    self.active_node.children[edge_char] = split

                    leaf = Node()
                    leaf.start = i
                    leaf.end = self.leaf_end

                    split.children[ch] = leaf
                    next_node.start += self.active_length
                    split.children[self.text[next_node.start]] = next_node

                    if last_new_node:
                        last_new_node.suffix_link = split
                    last_new_node = split

                self.remaining -= 1
                if self.active_node == self.root and self.active_length > 0:
                    self.active_length -= 1
                    self.active_edge = i - self.remaining + 1
                else:
                    self.active_node = self.active_node.suffix_link
```


## Testing with Large Text

```python
text = "a" * 10000 + "$"
st = SuffixTree(text)
print("Suffix tree built successfully")
```

This completes in **linear time** relative to input size.

##  Common Pitfalls

* Forgetting terminal symbol `$`
* Incorrect suffix link updates
* Not using shared end pointer for leaves
* Off‑by‑one errors in edge length


## Extensions

* Pattern search in **O(m)** time
* Longest repeated substring
* Longest common substring
* Convert to **C++** for massive datasets


##  Summary

> Ukkonen’s algorithm builds a **full suffix tree in linear time**, but is one of the most complex algorithms to implement correctly.

Use suffix trees when:

* You need **very fast substring queries**
* Memory is less critical than speed
