# Count Vowels and Consonants in a String

##  Problem Statement

Given a string, count how many **vowels** and **consonants** it contains.

### Assumptions

* Vowels are: **a, e, i, o, u** (case-insensitive)
* Consonants are alphabetic characters that are **not vowels**
* Ignore spaces, digits, and punctuation


##  Solution Approach

We:

1. Convert the string to lowercase
2. Iterate through each character
3. Check if it is an alphabetic character
4. Count vowels and consonants separately

This solution runs in **O(n)** time and uses **O(1)** extra space.



##  Python Implementation

```python
def count_vowels_and_consonants(s):
    vowels = set("aeiou")
    vowel_count = 0
    consonant_count = 0

    for ch in s.lower():
        if ch.isalpha():
            if ch in vowels:
                vowel_count += 1
            else:
                consonant_count += 1

    return vowel_count, consonant_count


text = "Hello World"
vowels, consonants = count_vowels_and_consonants(text)
print("Vowels:", vowels)
print("Consonants:", consonants)
```



## Example Output

```
Vowels: 3
Consonants: 7
```



##  Edge Cases

| Input           | Output                   |
| --------------- | ------------------------ |
| "AEIOU"         | Vowels: 5, Consonants: 0 |
| "Radar"         | Vowels: 2, Consonants: 3 |
| "123 !!"        | Vowels: 0, Consonants: 0 |
| "Hello, World!" | Vowels: 3, Consonants: 7 |

---

##  Notes

* Using a `set` for vowels provides **constant-time lookups**
* `isalpha()` ensures only letters are counted
* The approach is safe, readable, and interview-friendly
